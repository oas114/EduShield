自訂詞庫 (CSV) 功能

系統支援批次匯入您的自訂關鍵字、人名、專案代號等。請下載範本，依據「關鍵字,類別」格式填寫後上傳。類別為選填，若不填寫將自動設為 CUSTOM。系統會根據類別自動產生對應代碼（例如：NAME_1, CUSTOM_1）。
注意：關鍵字欄位值中不可含有逗號（,），否則將導致 CSV 解析錯誤。若詞彙本身含有逗號，請改用「線上建立詞庫」功能直接輸入。

地端 AI (Ollama) 連線設定

尚未安裝 Ollama 嗎？
請先前往 Ollama 官方網站下載 並完成安裝。安裝後，請開啟命令提示字元 (CMD) 或 PowerShell 並輸入以下指令來安裝預設模型：
ollama run qwen2.5:3b
為什麼需要這個設定？與潛在風險警告
Ollama 預設封鎖所有網頁的存取（安全保護機制）。需要在 Windows 中新增一個「環境變數」設定 OLLAMA_ORIGINS 為 *，告訴 Ollama 允許本機的 EduShield 網頁連線。

⚠️ 安全風險提示：
將來源設定為 * 代表允許任何網頁呼叫您的本地模型。雖然此設定僅影響您個人帳號且不需系統管理員權限，但仍存在遭其他惡意網頁濫用的風險。

強烈建議您在未使用本系統時，將系統匣的 Ollama 完全關閉（Quit Ollama），或於使用完畢後刪除該環境變數。

設定步驟（首次使用操作一次，之後每次開機自動生效）

1

先關閉 Ollama

在螢幕右下角系統匣（時鐘旁邊的小圖示區）找到 Ollama 羊駝圖示，對它按右鍵，選擇「Quit Ollama」完全關閉。

2

開啟 Windows「環境變數」設定視窗

點擊 Windows開始選單，在搜尋框輸入「編輯您帳戶的環境變數」，點選出現的結果。

或按 Win + R，輸入 sysdm.cpl 後按 Enter，再點「進階」→「環境變數」。

3

在上半部「使用者變數」中新增一筆

視窗分為上下兩個區域，請在上半部（您個人帳號的變數）點擊「新增(N)...」按鈕，並填入下列資料：

變數名稱 OLLAMA_ORIGINS
變數值 *

輸入完成後按「確定」，再按一次「確定」關閉整個環境變數視窗。

4

重新啟動 Ollama

從開始選單重新開啟 Ollama 應用程式，等系統匣出現羊駝圖示後，回到這裡按「測試連線」確認是否成功。

↩

日後如何取消這個設定？

重複步驟 2 開啟環境變數視窗，在上半部「使用者變數」中找到 OLLAMA_ORIGINS 這一筆，選取後按「刪除(D)」，重啟 Ollama 即完全還原。

不確定這個檔案安不安全？直接問 AI。

EduShield 是單一 HTML 檔案，沒有伺服器、沒有背景連線。您不需要看得懂程式碼——把整份 EduShield.html 原始碼貼給任何一個 AI（ChatGPT、Claude 等），直接問它：「這個網頁會不會把使用者輸入的資料傳送到任何地方？」讓 AI 幫您親自核實，而不是只聽開發者的一面之詞。

如何自行新增個資規則與硬阻斷關鍵字？

不需要手動修改 HTML 原始碼，請透過工具列的「管理自訂防護規則」介面操作：

  1. 點擊工具列的「管理自訂防護規則」，切換到「硬阻斷關鍵字」或「正則規則」分頁。
  2. 下載該分頁的 CSV 範本，依格式填入您的詞彙或正規表示式後存檔。
  3. 點「匯入 CSV」選擇該檔案，依需求選擇「新增並合併」或「完全取代」。
  4. 若希望往後每次開啟都自動套用，可在同一個管理介面展開「進階設定」（僅桌面版顯示）點「轉存為自動載入檔」，並將下載的 edushield.config.js 放到與 EduShield.html 相同的資料夾，並以本機檔案方式開啟才會生效。
  5. 若手動修改後想恢復成內建預設值，在「管理自訂防護規則」展開「進階設定」點「重新載入設定檔」即可（僅桌面版顯示）。
