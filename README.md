##  開發原由

在生成式 AI 普及的現在，許多教育工作者、社工與基層行政人員正面臨一個巨大的兩難：我們想利用 AI（如 ChatGPT、Claude）處理繁雜的公文與表格來提升效率，卻又深怕學生個資或機密資料外洩，面臨嚴重的法律風險[cite: 2]。

為了解決這個痛點，我開發了 **EduShield** ——一款完全免費、開源且極度安全的去識別化工具[cite: 2]。希望讓第一線人員能毫無顧忌地擁抱 AI，為您省下寶貴的加班時間[cite: 2]。

##  專案特點

* **極致的隱私安全（零信任架構）：** 採用純靜態單一 HTML 檔案設計[cite: 2]。您的資料不上傳雲端、不落地，關閉網頁即銷毀，徹底杜絕外洩風險[cite: 2]。
* **隨插即用零門檻：** 不需要懂程式或安裝複雜軟體，雙擊網頁即可為公文或表格進行「互動式遮蔽」，大幅節省手動打碼的加班時間[cite: 2]。
* **社會安全防護網（硬阻斷機制）：** 系統內建「硬阻斷（Hard Block）」機制，一旦偵測到如性平、家暴等特敏資訊，會強制鎖定防護，避免人員因疏忽而違反通報保密原則[cite: 2]。
* **混合式防禦：** 支援快速的靜態規則（Regex）比對，並可選用擴充地端 AI（Ollama）進行深度的語意與風險掃描。

##  使用說明

EduShield 的操作流程設計為直覺的「遮蔽 → 送 AI → 還原」核心三步驟：

1. **開啟系統：** 下載並於瀏覽器雙擊開啟 `EduShield.html`（或直接使用本專案的 GitHub Pages 線上版連結）。
2. **貼上與遮蔽：** 將公文或表格貼入左側「原始資料輸入區」，系統會自動偵測並將敏感個資（如姓名、身分證、成績）替換為代碼（如 `{{PERSON_1}}`）。
3. **安全對話：** 點擊「複製已遮蔽資料」，將去識別化後的文字貼給 ChatGPT 或 Claude 進行處理。
4. **一鍵還原：** 將外部 AI 產出的結果貼回系統的「外部 AI 回覆區」，點擊執行還原，系統會自動精準地把代碼替換回原本的真實資料。

>  **進階使用者與開發者請注意：**
> 關於自訂詞庫 (CSV) 格式、地端 AI (Ollama) 串接端點設定、正則表達式增修等詳細技術規格，請參閱完整的 **[EduShield 技術說明手冊 (EduShield_README.md)](./EduShield_README.md)**。
